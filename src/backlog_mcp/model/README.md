# Bundled multilingual embeddings

Source: [sentence-transformers/static-similarity-mrl-multilingual-v1](https://huggingface.co/sentence-transformers/static-similarity-mrl-multilingual-v1).

Converted with Model2Vec: Matryoshka truncation to 512 dimensions, int8 quantization, and normalized output. See `provenance.json` for the pinned revision and checksums, and `UPSTREAM.md` for the original model card.

This model is trained for sentence similarity. Backlog search ranks title, body, and tags by cosine similarity; it is not a retrieval-specific model.
